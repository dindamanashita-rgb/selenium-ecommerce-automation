# E-Commerce Website Automation Testing Using Selenium and Python

## Project Description

This project automates the testing of an e-commerce website using Python and Selenium WebDriver.

The automation performs important e-commerce activities such as opening the website, user login, searching for a product, selecting the product, adding the product to the shopping cart, and checking the cart.

## Technologies Used

- Python
- Selenium WebDriver
- Google Chrome
- GitHub
- Visual Studio Code

## Website Tested

TutorialsNinja Demo E-Commerce Website

## Test Flow

1. Open the e-commerce website
2. Navigate to My Account
3. Login using test credentials
4. Search for a product
5. Select the product
6. Add the product to the cart
7. Open the shopping cart
8. Verify the test flow

## Installation

Install Python and Selenium.

Run:

pip install selenium

## How to Run

Open the project in Visual Studio Code and run:

python test_ecommerce.py
